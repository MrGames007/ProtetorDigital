# 92 — Exercícios

## 🟢 Básico

1. **Enunciado:** encontre o texto do botão de retorno. **Dica:** procure `Text =`. **Gabarito:** ele está em um formulário/Designer de `Forms`.
2. **Enunciado:** identifique onde as perguntas são armazenadas. **Dica:** observe `dados`. **Gabarito:** `dados/perguntas.json`.
3. **Enunciado:** explique um model. **Dica:** veja suas propriedades. **Gabarito:** ele representa o formato de um registro JSON.

## 🟡 Intermediário

1. **Enunciado:** adicione uma dica sem quebrar a leitura. **Dica:** preserve `itens`. **Gabarito:** inserir objeto com os campos de `Dica`.
2. **Enunciado:** faça o link de um relato aparecer. **Dica:** valide o esquema. **Gabarito:** use URL absoluta `http` ou `https`.
3. **Enunciado:** explique o papel de `Responsivo`. **Dica:** observe `Registrar`. **Gabarito:** registra controles e escala fontes conforme a janela.

## 🔴 Avançado

1. **Enunciado:** rastreie uma pergunta até a tela. **Dica:** siga JSON → serviço/leitura → `Pergunta` → Quiz. **Gabarito:** a tela desserializa a lista e atualiza controles.
2. **Enunciado:** explique o fallback de janela. **Dica:** leia `JanelaPadrao.Aplicar`. **Gabarito:** usa tamanho padrão centralizado ou maximiza quando não cabe.
3. **Enunciado:** prepare uma publicação. **Dica:** leia o pubxml. **Gabarito:** use Release, win-x64, self-contained e single-file, mantendo dados/imagens.
