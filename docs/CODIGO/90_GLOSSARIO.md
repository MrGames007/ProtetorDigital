# 90 — Glossário A–Z

| Termo | Analogia | Onde aparece |
|---|---|---|
| Anchor | Elástico preso às bordas | Forms e designers |
| Assembly | Caixa final do aplicativo | `ProtetorDigital.csproj` |
| Binding | Ligação entre evento e método | Forms |
| ClientSize | Área interna da janela | `JanelaPadrao.cs` |
| ConteudoService | Bibliotecário dos JSONs | `Services/ConteudoService.cs` |
| Dock | Controle colado ao contêiner | Forms |
| Designer | Planta visual gerada pelo Visual Studio | `Forms/*.Designer.cs` |
| Event | Campainha que avisa uma ação | Forms |
| Fallback | Plano B de localização | carregadores JSON |
| FlowLayoutPanel | Fila que organiza controles | `FrmRelatos.Designer.cs` |
| Form | Janela do aplicativo | `Forms/*.cs` |
| JSON | Ficha externa de conteúdo | `dados/*.json` |
| LINQ | Filtro e transformação de listas | Quiz |
| Modal | Janela que bloqueia a anterior | Créditos |
| Model | Molde dos dados | `Models/*.cs` |
| Nullable | Aviso de valor que pode faltar | Models |
| Publish | Empacotamento para distribuição | `Windows.pubxml` |
| Responsivo | Régua que ajusta fontes | `Services/Responsivo.cs` |
| ShowDialog | Abrir uma janela modal | `FrmMenu.cs` |
| Uri | Endereço validado | `FrmRelatos.cs` |
| WinForms | Biblioteca de janelas Windows | `.csproj` |

## Pontos de atenção
Os nomes e exemplos refletem o código conferido em 2026-11-10; `Designer.cs` é gerado pelo Visual Studio.
